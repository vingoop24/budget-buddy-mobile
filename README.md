# Budget Buddy Mobile

AI-powered personal finance mobile app built with React Native and Expo.

## Features
- Budget dashboard with live spending totals
- Spending breakdown chart by category
- Recent expenses list
- Delete expense functionality
- AI assistant chat interface
- Receipt scanner screen
- Connects to FastAPI backend

## Tech Stack
- React Native
- Expo
- TypeScript
- React Native Chart Kit
- FastAPI backend
- OpenAI API integration

## Status
MVP in active development.

## Backend Repository
This frontend connects to the Budget Buddy API.
